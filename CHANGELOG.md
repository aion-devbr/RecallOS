## Registro herdado da base XMem

Os itens abaixo foram listados como “Unreleased” no changelog recebido com o XMem. O estado de publicação e a validação de cada recurso não foram confirmados nesta retomada:

- Cobrança modular com Razorpay, carteiras de créditos, reservas no ledger e medição de uso dos fluxos v2 de memória.
- APIs v2 de memória e scanner com Temporal, incluindo estado de tarefas, novas tentativas, cancelamento e fila de mensagens não processadas.
- Executores modulares dos benchmarks LoCoMo e BEAM para a API Python do XMem.
- Configuração local do XMem por meio de `npx create-xmem@latest` e `npm run dev`.
- Armazenamento local com Docker, ajustes de build da extensão do Chrome, diagnósticos, verificação e comandos para exportar, importar e sincronizar contexto.
